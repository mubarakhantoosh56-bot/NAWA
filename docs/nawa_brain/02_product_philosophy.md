# Product Philosophy

## What NAWA Is

NAWA is the Company Brain.

It connects human updates, files, chat, images, ERP data, HR data, sales data, accounting data, attendance systems, warehouse systems, operational events, and memory into one intelligent operating layer.

## What NAWA Is Not

NAWA is not ERP-first UI.

NAWA is not only a chatbot.

NAWA is not only a dashboard.

NAWA should not become a collection of rigid business modules before it understands the organization. ERP tables can exist later, but the product experience must feel like organizational intelligence first.

## Core Principle

Every input matters.

If a company has ERP, HR, sales, accounting, attendance, or warehouse systems, those systems are inputs to NAWA.

If a company has no ERP, NAWA provides lightweight native operational input through chat, forms, files, and manual updates.

The product should always preserve conversational power: users can ask anything and NAWA should answer using company context, memory, files, events, and organizational relationships.
