# UI Experience Principles

NAWA UI should feel like:

- Company Brain
- Organizational Intelligence
- Department Workspaces
- Live Operational Awareness

It should not feel like ERP-first screens.

## Main Workspace Direction

The main workspace should include:

- Left navigation for company brain, divisions, memory, reports, automations, and settings.
- Central conversation workspace where chat remains powerful.
- Operational input and file upload access.
- Right intelligence panel with live company intelligence.

## Jannat Workspace Navigation

The primary workspace should support:

- Jannat Al-Firdaws
- CEO Brain
- Dairtna Poultry
- Caesar Beverage
- Shared Corporate
- Company Memory
- Reports
- Automations
- Settings

## Experience Tone

The UI should be:

- Clean
- Premium
- Calm
- Executive
- Dense enough for operations
- Not marketing-heavy
- Bilingual and RTL/LTR aware
- Dark executive style where appropriate

Do not redesign for spectacle. Preserve usability, clarity, and the feeling that NAWA understands the organization.
