# NAWA Architecture — Index

**Scope of authority:** this directory is the canonical **NAWA Cognitive/System Architecture** — the product-level engine model (Knowledge Acquisition Engine, Operational Intelligence Engine, Operational Context Engine, Reasoning Engine, Executive Intelligence, Organizational Memory Engine) and how NAWA understands and reasons about a company as a living organization.

For the canonical **Engineering Implementation Architecture** — folder structure, layering, and coding-level rules for building NAWA — see [`ARCHITECTURE_RULES.md`](../../ARCHITECTURE_RULES.md) at the repository root.

The two are complementary, not competing: this directory governs *what the system cognitively does*; `ARCHITECTURE_RULES.md` governs *how the code implementing it is structured*. Neither supersedes the other.
